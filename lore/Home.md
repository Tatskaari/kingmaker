# Kingmaker Lore

Open this `lore` folder as an Obsidian vault. No community plugins are required.

## Lore from the issues
- [[World Overview]] — factions, places, events and rules.
- [[Cast Index]] — reusable character identities and relationships.
- [[Plot Index]] — the story threads described in the issues.
- [[Sources and Decisions]] — source links and unresolved lore questions.

## Playable material to sketch
[[Centennial Assembly]] indexes the scenario character briefs, quests, conversations and map. Agent entry files provide routing and blank core sections; supporting files contain only “This is a stub.” Add your sketches there before we expand them. [[Agent Disclosure]] defines GM and character context boundaries.

[[Authoring Guide]] explains where things belong. The vault is for authoring; the game still reads `content/`.
