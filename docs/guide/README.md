# The Kingmaker V2 GM guide

Everything we've learned about running GM-adjudicated scenes with an AI game master, in three parts:

- **[Authoring](authoring.md):** writing scenes, characters, the world and lore that the runtime plays well. It covers situations not plots, wants, relationships, secrets and contradictions, causes and fronts, and pacing in prep.
- **[Running](running.md):** what the runtime does each turn and why. It covers the GM's principles, the comic house style, dice on edges, narrative repair, pacing reveals, and memory (V1's docs service).
- **[Testing](testing.md):** blind QA, eval suites, and reading transcripts, with evals used as flags only.

The playable game is `npm run game` ([src/app](../../src/app/README.md)): the town on a map, its scenes, and the fight at the Heron. `npm run play` plays the same arc's scenes in the scene harness, one after another, with interludes in place of the map (hanged clerk → the town → the Drowned Rat → the wharves → the Heron → the King's morning). The story behind each decision is in [FINDINGS.md](../FINDINGS.md), [experiments/](../experiments/) and [research/](../research/).
