# Caerwyn pencil atlas

Original game artwork generated with the built-in ImageGen tool, using the first tabletop atlas as a layout reference and the user's supplied battle-map image as a style reference. The PNG has genuine alpha transparency, 12 columns and 11 rows. Runtime cropping uses the image's natural dimensions because its cells are not an integer number of source pixels. Logical game tiles remain 16 × 16.

Generation prompt:

> Use case: style-transfer. Asset type: production game sprite atlas. EDIT IMAGE 1; IMAGE 2 IS STYLE REFERENCE ONLY. Redraw image 1 in the hand drawn ink and coloured-pencil battle-map style of image 2. Crucial technical constraint: preserve the EXACT 12 columns x 11 rows of equal square cells, sprite locations, empty transparent cells, tile silhouettes and contents. Canvas aspect ratio 12:11, ideally 1536x1408 pixels. Keep transparent pixels transparent. Do not shift, enlarge, rearrange or add sprites, no margins or captions. Each source cell remains a separate cell. Floor cells (row 5 columns 1,2,3 one-based) must fill their square edge to edge with pale warm grey stone, irregular small pencil-outlined flagstones and restrained pencil grain. Wall sprites keep exact occupied square footprint and directional edges, but use irregular dark hand ink outlines, hatching, muted grey-beige rough masonry. The upper-left cell is muted parchment earth. Furniture is top-down ink and coloured pencil walnut wood, sage blankets, brass details. Bottom four rows retain round character portrait counters at identical centres and sizes, with loose expressive ink and coloured-pencil faces/clothes, not shiny digital coins. The chest at row 8 column 7 remains a chest. Overall visible pencil strokes, paper tooth, broken hand-drawn contours, subdued natural colours, soft irregular graphite shadows, no glossy gradients, no vector-perfect lines, no pixel art. Match the reference's handmade tabletop map feeling while preserving image 1's precise atlas layout so game tile cropping still works.

Alpha cleanup prompt:

> Precise background-extraction edit for a production game atlas. Keep every drawn sprite exactly where it is and preserve all colours, pencil shading, scale, grid alignment and outlines. Remove ALL the grey/white checkerboard background and replace it with genuine transparent alpha (RGBA PNG). The checkerboard is not artwork and must NOT be present in output pixels. No checkerboard, no white backdrop, no new texture outside sprites. Preserve the exact 12 columns by 11 rows atlas. Keep all empty cells completely transparent and the spaces around tokens/furniture transparent. Full stone/floor squares remain opaque. Do not redraw or rearrange artwork. Output transparent PNG.
