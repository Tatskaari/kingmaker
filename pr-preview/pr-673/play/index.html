The Game Master is a language model reached through OpenRouter, so it needs an OpenRouter key. The whole game runs on this page.

Checking the key with OpenRouter…

It's kept in this browser (also for the other Kingmaker previews on this site, though each keeps its own games) and sent only to OpenRouter, from this page. Change or forget it under the game. Get a key at openrouter.ai/keys

The fake GM needs no key and costs nothing: it plays canned replies, which don't answer what you say. You can make a character, walk the town and see a scene play.
