; Kingmaker Glyphs: the bitmaps. Draw here, then `npm run glyphs` (build and install) and
; `npm run glyphs:sheet` (contact sheets in runs/glyphs/). See tools/glyphs/README.md.
;
; Each glyph is a header line (its name, its code point, what it is), then one row per line of the
; grid: '#' is ink, '.' is blank. The grid is one terminal cell at one screen pixel a design pixel
; (Adwaita Mono 11 at 96 dpi: a 9 x 20 cell), 14 rows above the baseline and 4 below, so nothing is
; smeared across two pixels. Leave the last column blank: it's the gap that keeps neighbours apart
; (the build refuses ink there). Feet stand on the bottom row; adults are about 16 rows tall,
; children 10 or 11, beasts by their size.
;
; Code points never change once given (saves and other tools may hold them): the cast from
; U+10E000, townsfolk from U+10E040, creatures from U+10E080, animation frames from U+10E0C0.
; Anything after ';' is a comment.
